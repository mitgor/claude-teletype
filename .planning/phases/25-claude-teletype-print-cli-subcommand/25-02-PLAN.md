   ```python
   def _make_markdown_picker_app(
       config,
       all_profiles: dict,
       resolved_profile,
       root: Path | None = None,
   ):
       """Build a minimal Textual App that runs the markdown picker and exits.

       Lazily imports textual so cli.py top-level remains lightweight when
       the user invokes only the explicit-path branch or non-interactive
       commands like `config show` or `diagnose`.
       """
       from textual.app import App
       from claude_teletype.file_picker_screen import FilePickerScreen

       class MarkdownPickerApp(App):
           """Minimal one-shot picker launcher for `claude-teletype print` (CLI-02).

           Pushes FilePickerScreen on mount; the dismiss callback either
           prints the selected file via the Plan 25-01 helper or exits
           cleanly on cancel. No chat tree, no input prompt, no transcript
           -- the app exists only to bridge the no-arg CLI to the picker.
           """

           CSS = ""  # no chrome

           def __init__(self_app) -> None:
               super().__init__()
               self_app._exit_code: int = 0

           def on_mount(self_app) -> None:
               self_app.push_screen(
                   FilePickerScreen(root=root),
                   callback=self_app._on_pick,
               )

           def _on_pick(self_app, result) -> None:
               """Handle picker dismiss.

               None -> cancel: exit 0, no print started.
               Path -> render then exit with the helper's return code.
               """
               if result is None:
                   self_app._exit_code = 0
                   self_app.exit()
                   return
               # result is a Path. Render synchronously (blocks the picker
               # until print completes) then exit.
               self_app._exit_code = _render_markdown_to_driver(
                   result, config, all_profiles, resolved_profile,
               )
               self_app.exit()

       return MarkdownPickerApp()
   ```

   IMPORTANT design notes:
   - We define the App class INSIDE a factory function so we can capture
     `config`, `all_profiles`, `resolved_profile`, `root` as closure
     variables -- avoids polluting the App's `__init__` signature with
     constructor args (matches how `TeletypeApp` accepts them, but we
     don't need that complexity for a one-shot launcher).
   - We use `self_app` as the `self` parameter name inside the nested
     class only because `self` would shadow nothing -- the rename is
     purely for readability; you may use `self` instead, but be sure not
     to confuse it with the outer scope (there is no outer `self` here
     because `_make_markdown_picker_app` is a module-level function, so
     `self` is fine).
   - **Recommendation: use `self`** in the actual implementation for
     idiomatic Python; the `self_app` rename above is illustrative only.
   - The render call IS synchronous and IS inside the picker callback.
     This means the user picks a file, the picker dismisses (the screen
     unmounts), and the render runs in the foreground (Textual's worker
     loop is not involved). For Phase 25 the print is non-paced, so the
     render is fast (it's just file I/O + USB write, no `await asyncio.sleep`
     between chars). Phase 26's pacer will need to refactor this into a
     worker, but that's Phase 26's territory per the quality gate.
   - The exit code is stored on the app instance and read by the caller
     after `.run()` returns. Textual's `App.exit(result)` doesn't have a
     standard "return code" pattern; the attribute approach is the
     existing project convention (see `TeletypeApp.session_id` set
     during `.run()` and read after).

       #   (a) Extract a private `_resolve_print_context(delay, device,
       #       printer) -> tuple[config, all_profiles, resolved_profile]`
       #       and call it from both _print_command_impl and
       #       _print_command_impl_picker -- DRY.

       #       but keeps Plan 25-01's signature totally unchanged.

       config, all_profiles, resolved_profile = _resolve_print_context(
