Build the detection seam the fleet phases consume, and fix two device-selection tech-debt items:
- **DET-02:** Introduce `printing/detection.py` with `DeviceKind` (NATIVE_PRINTER / BRIDGE / UNKNOWN) + a `Classification` dataclass + `classify(dev, registry)`. This replaces the conflated `auto_detect_profile()` path that mixes "found a device" with "know what it is."

Scope is the TYPE + SEAM only — NO new detection DATA (BRIDGE_CHIP_VIDS population, VID matrix expansion, removing the juki bridge-VID pin) is Phase 28.
Output: detection.py + Classification; identity-based selection; typed setup-decision sentinel; tests; full suite green.
