    **on_mount() logic:**
    1. Populate OptionList with device entries:
       - USB devices: `"{product_name} (USB {vendor_id:04x}:{product_id:04x})"` or `"USB Device ({vendor_id:04x}:{product_id:04x})"` if no product_name
       - CUPS printers: `"{name} (CUPS{': ' + model if model else ''})"` 
       - If no devices at all: add single item `"No printers found. Check connections or install USB support."`
    2. Populate profile Select with sorted keys from all_profiles: `[(name, name) for name in sorted(self._all_profiles.keys())]`, default value "generic"
    3. Write diagnostic messages from `self._discovery.diagnostics` into the Log widget
    4. Add summary diagnostics:

       - If cups_printers: `"{n} CUPS queue(s) found"`
       - If not cups_printers: `"No CUPS queues found"`
    5. If `discovery.pyusb_available` is True: hide install-row (`self.query_one("#install-row").display = False`)
    6. If `discovery.pyusb_available` is False: log `"pyusb not installed -- USB detection unavailable"`
    7. If no devices found: disable connect-btn (`self.query_one("#connect-btn").disabled = True`)
    8. Initially disable both radio buttons until a device is selected

    **Store device metadata for selection mapping:**
    - `self._device_entries: list[dict]` -- list of dicts with keys `type` ("usb"|"cups"), `index` (position in usb_devices or cups_printers list), `usb_info` or `cups_info` as applicable. Built during on_mount population. Index in this list matches OptionList option index.

    **on_option_list_option_selected(self, event: OptionList.OptionSelected):**
    - Look up `self._device_entries[event.option_index]`
    - If type=="usb": enable both radio buttons, auto-select "USB Direct" (`self.query_one("#radio-usb").value = True`), call auto-detect for profile
    - If type=="cups": auto-select "CUPS Queue" (`self.query_one("#radio-cups").value = True`), disable "USB Direct" radio, set profile to "generic"
    - Enable connect-btn
    - For USB auto-detect: check `discovery.pyusb_available`, if True look up `auto_detect_profile()` result by matching VID:PID against profiles, set `Select` value. If pyusb not available or no match, default to "generic". Use a local VID:PID matching loop against `self._all_profiles` instead of calling `auto_detect_profile()` directly (avoids pyusb import per Pitfall 6 in research).

    **_on_connect (on_button_pressed for connect-btn):**
    - Get highlighted option index from OptionList
    - Get selected radio (check `#radio-usb` value for USB, else CUPS)
    - Get selected profile name from Select widget
    - Build PrinterSelection:
      - connection_type: "usb" or "cups"
      - device_index: the index from _device_entries
      - cups_printer_name: from _device_entries if CUPS
      - profile_name: from Select value
    - `self.dismiss(selection)`

    **_on_skip (on_button_pressed for skip-btn) and action_skip:**
    - `self.dismiss(None)`

    **on_button_pressed dispatch:**
    - `if event.button.id == "connect-btn": self._on_connect()`
    - `elif event.button.id == "skip-btn": self._on_skip()`
    - `elif event.button.id == "install-btn": self._install_pyusb()`

    **_install_pyusb() -- @work(exclusive=True, thread=False) async worker:**
    Follow Pattern 3 from research exactly:
    1. `import shutil` and check `shutil.which("uv")` -- if None, log "Error: uv not found on PATH" and return
    2. Show spinner: `self.query_one("#install-spinner").display = True`
    3. Disable install button: `self.query_one("#install-btn").disabled = True`
    4. Log: `"Installing pyusb via uv sync --extra usb..."`
    5. `proc = await asyncio.create_subprocess_exec("uv", "sync", "--extra", "usb", stdout=PIPE, stderr=PIPE)` (use full path from shutil.which)
    6. `stdout, stderr = await proc.communicate()`
    7. Hide spinner
    8. If returncode == 0:
       - Log "pyusb installed successfully."
       - Call `_reimport_pyusb()` -- if returns True: log "USB support activated. Re-scanning devices...", call `_refresh_discovery()`
       - If reimport fails: log "Installed but import failed. Restart app to detect USB devices."
    9. If returncode != 0: log `f"Install failed: {stderr.decode().strip()}"`, re-enable install button

    **_reimport_pyusb() -> bool:**
    Follow Pattern 4 from research:
    ```python
    import importlib
    import sys
    usb_keys = [k for k in sys.modules if k.startswith("usb")]
    for key in usb_keys:
        del sys.modules[key]
    importlib.invalidate_caches()
    try:
        import usb.core
        return True
    except ImportError:
        return False
    ```

    **_refresh_discovery():**
    1. `from claude_teletype.printer import discover_all`
    2. `self._discovery = discover_all()`
    3. Clear and repopulate OptionList with new discovery data
    4. Hide install-row if pyusb now available
    5. Enable/disable connect-btn based on device count
    6. Log new device counts

    **macOS default (Pitfall 4):**
    In on_option_list_option_selected, when USB device is selected and `sys.platform == "darwin"`, default radio to "CUPS Queue" instead of "USB Direct". Log "macOS kernel driver conflict -- use CUPS queue instead" if both USB and CUPS are available for the same device.
