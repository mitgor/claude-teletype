<!-- Keybinding choice rationale (CONTEXT.md "Keybinding entry from main TUI" + "Claude's Discretion") -->

Existing bindings: ctrl+d (quit), ctrl+t (typewriter), ctrl+comma (settings), escape (cancel_stream).
Chosen: ctrl+o ("open file"). Conflict check:
- Not in TeletypeApp.BINDINGS — clean.
- Not in Textual App.BINDINGS default set (Textual reserves ctrl+c for quit-on-some-platforms, ctrl+p for command palette in some apps; ctrl+o is unreserved).
- Note on terminals: some legacy terminals send ctrl+o as "discard output" (XOFF-adjacent). In Textual's input layer this is captured as `key=ctrl+o` regardless — same mechanism that lets nano use ctrl+o for "Write Out". No issue in practice.
- Footer label: "Open MD" (short, matches existing labels like "Quit", "Typewriter", "Settings").

Fallback if ctrl+o turns out conflicting on a target platform: ctrl+shift+o or ctrl+p (markdown print). The action_open_markdown handler name is binding-agnostic so the BINDINGS line can be edited without touching the handler. Document this in the action's docstring.

        path: Path = result
        self.notify(f"Selected: {path}")
        self.query_one("#prompt", Input).focus()
