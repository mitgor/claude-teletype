<objective>
Add a `write_bytes(data: bytes) -> None` public method to the `PrinterDriver` Protocol and to all five concrete driver implementations (Null, File, Cups, Usb, Profile). This method is the foundation for the markdown renderer's style channel — it lets the renderer send raw ESC byte sequences (e.g., `\x1bE` for bold-on, `\x1bF` for bold-off) atomically, bypassing per-character word-wrap and pacing.

Purpose: The markdown renderer (Plan 23-02 + 23-03) needs two output channels — one for plain visible characters that goes through `WordWrapper` + `pacer`, and one for ESC control codes that must transfer atomically. `ProfilePrinterDriver.write` already uses `_send_raw` internally for init/reinit sequences, but it's a private method. Exposing a public `write_bytes` gives the renderer a clean, type-safe seam without callers reaching for `_send_raw`. Adding it to the Protocol means the renderer can accept any `PrinterDriver` and call `write_bytes`, not just `ProfilePrinterDriver`.

Output: 5 new method implementations + 1 Protocol method declaration in `src/claude_teletype/printer.py`; 5 new test methods (one per driver) in `tests/test_printer.py`.
</objective>
