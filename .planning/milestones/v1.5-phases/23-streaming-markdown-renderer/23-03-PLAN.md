<objective>
Add inline emphasis parsing (bold + italic via `**bold**`/`__bold__` and `*italic*`/`_italic_` markers) to the `MarkdownRenderer` from Plan 23-02. The state machine recognizes emphasis markers, calls `resolve_style(profile, "bold"|"italic")` to determine the active profile's on/off byte sequences, and emits those bytes through `style_output_fn` while the visible text continues flowing through `text_output_fn`. This satisfies MD-01 and completes the renderer's MD-01..MD-08 contract.

Plus a strict symmetry-safety pass: every emitted style_on has a matching style_off (closed at end-of-line for heading/list-item boundaries, end-of-document for unclosed emphasis, and end-of-block for blockquote/list-item closures). This prevents bold/italic mode from leaking past the markdown construct that opened it — critical for the printer pipeline since style modes persist on hardware until explicitly cleared.

Plus the canonical integration test: a complete markdown document containing every supported feature, rendered through a real `WordWrapper(80)` against a real built-in `PrinterProfile`, with hand-checked expected output for both the text channel and the style channel. This is the user-acceptance gate for "markdown rendering works end-to-end."

Purpose: Inline emphasis is the visual signal that makes markdown printing feel like real typography. Without bold/italic the document still has structure (Plan 23-02) but no emphasis; this plan delivers the dressing. The integration test is what proves the whole MD-01..MD-08 system composes correctly.

Output: ~80-150 LOC added to `markdown.py` (replace `_render_inline` stub + add helper methods); ~150-250 LOC added to `tests/test_markdown.py`.

<!-- resolve_style from src/claude_teletype/profiles.py — the renderer's import contract -->

```python
def resolve_style(profile: PrinterProfile, style: str) -> tuple[bytes, bytes]:
    """Return (on_bytes, off_bytes) for 'bold' | 'italic' | 'underline'.

    Fallback chain:
    - italic → italic codes if non-empty, else underline codes if non-empty, else (b"", b"")
    - bold → bold codes if non-empty, else underline codes if non-empty, else (b"", b"")
    - underline → underline codes if non-empty, else (b"", b"")

    (b"", b"") means the renderer should emit plain text with no styling.
    """
```

<!-- Reference resolve_style values for built-in profiles (from Phase 22) -->
- escp: bold=(b"\x1bE", b"\x1bF"), italic=(b"\x1b4", b"\x1b5"), underline=(b"\x1b-\x01", b"\x1b-\x00")
- ppds: bold=(b"\x1bE", b"\x1bF"), italic=(b"\x1b%G", b"\x1b%H"), underline=(b"\x1b-\x01", b"\x1b-\x00")
- pcl: bold=(b"\x1b(s3B", b"\x1b(s0B"), italic=(b"\x1b(s1S", b"\x1b(s0S"), underline=(b"\x1b&dD", b"\x1b&d@")
- juki-6100 / juki-2200: bold falls back to underline (b"\x1b-\x01", b"\x1b-\x00"); italic falls back to underline; underline direct
- generic: all (b"", b"")

      ```python
          return
      ```

      ```python
      if off:
          self._style_output_fn(off)
      ```
    - When `resolve_style` returns `(b"", b"")` (e.g., generic profile), `on` is empty → no emit (the `if on:` guard).

    **State machine in `_render_inline(text: str) -> None`:**
    ```python
    def _render_inline(self, text: str) -> None:
        i = 0
        n = len(text)
        while i < n:
            # Greedy: ** beats *, __ beats _
            if i + 1 < n and text[i] == "*" and text[i + 1] == "*":
                self._toggle_bold()
                i += 2
                continue
            if i + 1 < n and text[i] == "_" and text[i + 1] == "_":
                self._toggle_bold()
                i += 2
                continue
            if text[i] == "*":
                self._toggle_italic()
                i += 1
                continue
            if text[i] == "_":
                self._toggle_italic()
                i += 1
                continue
            self._text_output_fn(text[i])
            i += 1
    ```

    ```python
    if self._bold_open:

        self._bold_open = False
    else:

        self._bold_open = True
    ```
