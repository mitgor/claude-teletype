From 27-PATTERNS.md "Test Patch-Target Migration": highest-risk call-assertion patch targets are `claude_teletype.printer.discover_printer` (×30) and `claude_teletype.printer.subprocess` (×27). After this step repoints cli/tui to import discover_printer/discover_all from printing.selection/printing.discovery, a test that does `patch("claude_teletype.printer.discover_printer")` AND asserts `.assert_called()` will patch the shim's re-exported name — which production no longer reads — and FAIL. Tests that only check the *return value* (not call assertions) still pass because the patched function still executes through the shim re-export resolution. Rule: run the suite; for any newly-failing test, move ITS patch target string to the new module in THIS plan. Tests that remain green stay untouched until Step 3.
