Create a new file `src/claude_teletype/settings_screen.py` containing `SettingsScreen(ModalScreen[dict | None])`.

The screen takes constructor parameters for current values:

- `current_no_audio: bool` — whether audio is disabled
- `current_backend: str` — backend name (claude-cli, openai, openrouter)
- `current_model: str` — model name (may be empty)
- `current_profile: str` — printer profile name
- `available_profiles: list[str]` — list of profile names for Select dropdown

Compose layout inside a `Vertical(id="settings-dialog")`:
1. `Static("Settings", id="settings-title")` — title
2. `Label("Character Delay (ms)")` + `Input(value=str(delay), type="number", id="delay-input")`
3. `Label("Audio Enabled")` + `Switch(value=not no_audio, id="audio-switch")` — note the inversion: Switch ON = audio enabled, but app stores `no_audio`
4. `Label("Printer Profile")` + `Select[str]` with `(name, name)` tuples from available_profiles, `value=current_profile`, `allow_blank=False`, `id="profile-select"`
5. `Label("LLM Backend")` + `Select[str]` with options `("Claude CLI", "claude-cli"), ("OpenAI", "openai"), ("OpenRouter", "openrouter")`, `value=current_backend`, `allow_blank=False`, `id="backend-select"`
6. `Label("Model")` + `Input(value=current_model, id="model-input", placeholder="Leave empty for backend default")`
7. `Horizontal(id="button-row")` containing `Button("Save", variant="primary", id="save-btn")` and `Button("Cancel", id="cancel-btn")`

BINDINGS: `[Binding("escape", "cancel", "Cancel")]`

CSS: Center the dialog, set width to 60, height auto, max-height 80%, border thick, background $surface, padding 1 2. Style the title bold and centered. Add margin-top 1 to labels (via `.setting-label` class). Style button row with margin-top 1 and center alignment.

- If save-btn: collect values from all widgets, dismiss with dict `{"delay": float, "no_audio": bool, "backend": str, "model": str, "profile": str}`. Parse delay with float() in try/except, falling back to original value. Invert Switch value for no_audio.
- If cancel-btn: dismiss(None)

action_cancel: dismiss(None)

Follow the TypewriterScreen module style: `from __future__ import annotations`, standard imports at top, docstring on class.
