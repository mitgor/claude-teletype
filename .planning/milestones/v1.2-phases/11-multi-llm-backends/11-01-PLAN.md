Create `src/claude_teletype/backends/openai_backend.py` with:

**`OpenAIBackend(LLMBackend)`:**
- Constructor: `(api_key: str | None, model: str, system_prompt: str | None = None, base_url: str | None = None)`
  - Creates `AsyncOpenAI(api_key=api_key, base_url=base_url, max_retries=0)` — disable SDK retries so TUI retry loop handles consistently (per research recommendation)
  - Stores `_model`, `_system_prompt`, `_history: list[dict[str, str]]` (empty initially)
- `validate()`: raises `BackendError("OPENAI_API_KEY environment variable not set. ...")` if `self._client.api_key` is falsy (include guidance text)
- `add_to_history(role, content)`: appends `{"role": role, "content": content}` to `self._history`
- `stream(prompt)`:
  1. Calls `self.add_to_history("user", prompt)`
  2. Builds messages list via `_build_messages()`
  3. Creates `await self._client.chat.completions.create(model=self._model, messages=messages, stream=True)`
  4. Iterates chunks: guard `if chunk.choices and chunk.choices[0].delta.content` before yielding `delta.content`
  5. Accumulates content into `assistant_content` list
  6. After stream completes: `self.add_to_history("assistant", "".join(assistant_content))`
  7. Yields `StreamResult(model=self._model, is_error=False)`
  8. Wraps in try/except catching:
     - `openai.AuthenticationError` -> `StreamResult(is_error=True, error_message="Authentication failed: ...")` — matches ERROR_PATTERNS "authentication"
     - `openai.RateLimitError` -> `StreamResult(is_error=True, error_message="Rate limit exceeded: ...")` — matches "rate limit"
     - `openai.APIConnectionError` -> `StreamResult(is_error=True, error_message="Network error - connection failed: ...")` — matches "network"
     - `openai.APIError` -> `StreamResult(is_error=True, error_message=str(e))` — catch-all
- `_build_messages()`: returns list starting with system message (if set) then `self._history`

**`OpenRouterBackend(OpenAIBackend)`:**
- Constructor: `(api_key: str | None, model: str, system_prompt: str | None = None)`
  - Calls `super().__init__(api_key=api_key, model=model, system_prompt=system_prompt, base_url="https://openrouter.ai/api/v1")`
- `validate()`: raises `BackendError("OPENROUTER_API_KEY environment variable not set. ...")` if `self._client.api_key` is falsy
