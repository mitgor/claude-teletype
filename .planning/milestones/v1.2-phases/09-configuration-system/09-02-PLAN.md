<task type="auto">
  <name>Task 1: Restructure Typer CLI with callback + config subcommands</name>
  <files>src/claude_teletype/cli.py</files>
  <action>
    Restructure cli.py to support both the existing chat behavior AND a `config` subcommand group:

    1. **Create config subcommand group:**
       ```python
       config_app = typer.Typer(help="Manage configuration")
       app.add_typer(config_app, name="config")
       ```

    2. **Add `config show` subcommand:**
       ```python
       @config_app.command()
       def show():
       ```
       - Import and call `load_config()`, `apply_env_overrides()`
       - Print each config key and value using `typer.echo()`
       - Show config file path and whether it was loaded
       - Show any active env var overrides

    3. **Add `config init` subcommand:**
       ```python
       @config_app.command("init")
       def init_config():
       ```
       - Import and call `write_default_config()`
       - Print the path where the config file was written
       - If file already exists, warn and do not overwrite (ask or skip)

    4. **Convert `@app.command() def chat(...)` to `@app.callback(invoke_without_command=True) def main(...):`**
       - Move ALL existing CLI options from `chat()` to `main()`
       - Add `ctx: typer.Context` as first parameter
       - Add `init_config_flag: bool = typer.Option(False, "--init-config", help="Create config file with defaults")`
       - **CRITICAL:** Change configurable option defaults to `None` to enable config merge:
         - `delay: float = typer.Option(None, ...)` (was 75.0)
         - `no_audio: bool` — keep as `typer.Option(False, ...)` for boolean since None sentinel is tricky with Typer booleans. Accept that CLI boolean flags always win over config.
         - `no_tui: bool` — same as no_audio, keep False default
         - `transcript_dir: str = typer.Option(None, ...)` (already None)
         - `device: str = typer.Option(None, ...)` (already None)
         - `juki: bool` — keep False default (same boolean consideration)
       - Add early return: `if ctx.invoked_subcommand is not None: return`
       - Add init-config handling: `if init_config_flag: write_default_config(); raise typer.Exit()`

    5. **Wire config loading into the main flow:**
       After the subcommand/init-config checks, before `check_claude_installed()`:
       ```python
       from claude_teletype.config import load_config, apply_env_overrides, merge_cli_flags
       config = load_config()
       config = apply_env_overrides(config)
       config = merge_cli_flags(config, delay=delay, device=device, transcript_dir=transcript_dir)
       ```
       Then use `config.delay`, `config.device`, etc. throughout the rest of the function instead of the raw CLI parameters. For boolean flags (no_audio, no_tui, juki) that keep their False defaults, use `no_audio or config.no_audio` pattern (CLI flag wins if True, config wins if CLI is False).

    6. **BACKWARD COMPATIBILITY:** The restructure MUST preserve:
       - `claude-teletype "hello"` works (prompt as positional arg)
       - `claude-teletype --delay 50 "hello"` works
       - `claude-teletype` with no args launches TUI
       - `claude-teletype --no-tui "hello"` works
       - `claude-teletype --teletype` works
       - `claude-teletype --resume <id>` works

    **Pitfall watch (from research):** If Typer interprets `claude-teletype config` as prompt="config", the positional argument conflicts with the subcommand name. Test this carefully. The `ctx.invoked_subcommand` check in the callback should handle it, but verify.
