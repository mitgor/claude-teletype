**audio.py** -- Add `make_keystroke_output()` function below the existing `make_bell_output()`:
- Follow the exact same pattern as `make_bell_output()`: lazy import numpy+sounddevice in try/except, return Callable[[str], None] or no-op.
- Generate a short (~20ms) typewriter click sound in-memory: mix white noise burst + low thump (200Hz sine), apply rapid exponential decay (`np.exp(-t * 200)`), normalize to 0.5 amplitude. Use `np.random.default_rng(42)` for deterministic noise.
- The returned callable should call `sd.play(click, samplerate=sr)` for every character EXCEPT `"\n"` and `"\r"` (those get the bell sound, not a click).
- Pre-generate the click array once at factory time, not per-call.

**typewriter_screen.py** -- Create new file `src/claude_teletype/typewriter_screen.py`:
- Import from textual: `events`, `work`, `Binding`, `Screen`, `Footer`, `Header`, `Log`, `Static`.
- `TypewriterScreen(Screen)` class with:
  - `BINDINGS = [Binding("escape", "app.pop_screen", "Back to Chat")]`
  - CSS: `#typewriter-output { height: 1fr; }` and `#typewriter-status { dock: bottom; height: 1; background: $surface; color: $text-muted; padding: 0 1; }`
  - `__init__(self, base_delay_ms: float = 75.0, printer=None, no_audio: bool = False, **kwargs)` -- store params, set `self._key_queue = None` and `self._output_fn = None`.
  - `compose(self)` -- yield Header, Log(id="typewriter-output", auto_scroll=True), Static with printer status ("TYPEWRITER MODE | Printer: connected/none"), Footer.
  - `on_mount(self)` -- Create `asyncio.Queue()` here (not in __init__, to avoid event loop mismatch). Build output destinations list:
    1. `log.write` (from `self.query_one("#typewriter-output", Log)`)
    2. `make_printer_output(self._printer)` if printer is connected
    3. `make_keystroke_output()` if not no_audio
    4. `make_bell_output()` if not no_audio
    Then create `self._output_fn = make_output_fn(*destinations)`. Call `self._process_keys()`.
  - `on_key(self, event: events.Key)` -- Capture keystrokes:
    - If `event.is_printable and event.character`: `prevent_default()`, `stop()`, `put_nowait(event.character)`
    - If `event.key == "enter"`: `prevent_default()`, `stop()`, `put_nowait("\n")`
    - If `event.key == "tab"`: `prevent_default()`, `stop()`, `put_nowait("\t")`
    - Ignore backspace (typewriter authenticity -- append-only).
  - `@work(exclusive=True) async def _process_keys(self)` -- Loop forever: `char = await self._key_queue.get()`, then `await pace_characters(char, base_delay_ms=self._base_delay_ms, output_fn=self._output_fn)`.

Key points from research:
- Do NOT use an Input widget in the TypewriterScreen (it would capture key events).
- Create asyncio.Queue in on_mount, not __init__.
- Use @work(exclusive=True) for the processing loop.
- All pacing uses asyncio.sleep via pace_characters (never time.sleep).
