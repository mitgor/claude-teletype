<objective>
Extract the ~90-line print pipeline duplicated between `cli.py:_render_markdown_to_driver` and `tui.py:_run_print_pipeline` (ARCH-01) into one shared `render_document` function in `printing/pipeline.py`, then rewire the two CLI consumers (explicit-path and picker) as thin adapters. Fix WR-04 in the same pass: the picker adapter resolves its printer driver *before* `picker_app.run()`, so `select_printer()`'s interactive `input()` loop can never fire while Textual owns the terminal.

Purpose: PIPE-01 must land before the PIPE-02 cancel fix (Plan 33-02) because consolidation changes the exact code the cancel fix touches. This plan settles the shared core's shape — cancel-safety (`finally: renderer.close()`), injectable pacing, injectable cancel check — so the TUI adapter in Wave 2 is a thin consumer.

Output: `printing/pipeline.py` (new), refactored `cli.py` adapters, `tests/test_pipeline.py` (new), updated `tests/test_cli_print.py`.
</objective>

| T-33-03 | Info Disclosure | transcript fan-out | mitigate | TXN-02 preserved: collector taps only the text channel; test asserts no ESC bytes in transcript body |

No new packages installed in this phase — package legitimacy gate not applicable.
