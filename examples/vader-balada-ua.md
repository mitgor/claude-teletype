# Балада про дядька в чорному шоломі

*Іронічна поема в семи строфах. Не для слабкодухих імперців.*

> **Технічна примітка:** Цей файл містить українські літери **і, ї, є, ґ**.
> Деякі з них (`і/І/ґ/Ґ`) відсутні в CP866, але профіль `citizen-cts2000`
> має вбудовану таблицю **text_fallback**, яка автоматично замінює їх на
> близькі аналоги (`і → i`, `Ґ → Г`). Тож друкувати можна одразу:
>
> ```
> claude-teletype print examples/vader-balada-ua.md
> ```
>
> Якщо хочеш справжні українські гліфи замість латинських — встанови
> `text_codec = "cp1125"` у власному профілі (приклад у кінці файлу).

---

## I. Експозиція

В одній *далекій-далекій* галактиці,
Де навіть пиріжки літають у вакуумі,
Жив-був собі **Дарт Вейдер** — лорд,
Який забув, як виглядає сонце.

Він дихав, як стара колонка ЖЕКу:
*Хх-пшш... хх-пшш...* — на всю Зірку Смерті.
Сусіди скаржилися, але — кому?
Імперський відділ скарг закритий *назавжди*.

## II. Біографічна довідка

Колись він був **Енакін Скайвокер** —
хлопчина з планети **Татуїн**.
Мріяв стати джедаєм, гонщиком, святим, —
а став... ну, ви самі бачили чим.

| Що мав    | Що отримав            |
|-----------|-----------------------|
| Кохання   | Втратив                |
| Дітей     | Не знав про існування  |
| Майбутнє  | Темне, як його шолом   |
| Шеф       | *Палпатін* — без коментарів |

## III. Робочі будні Лорда Сітхів

Імперія — це не лише гнобити повстанців.
Це ще й **звітність**, *планерки* і ранкові наради
з адміралами, що носять смішні шапки
і весь час намагаються кого-небудь задушити подумки.

- **Понеділок:** інспекція штурмовиків (знов промахуються!)
- **Вівторок:** наради з Палпатіном (*"Так, мій володарю"*)
- **Середа:** душіння віддалено через Силу
- **Четвер:** пошук бунтівних дроїдів (**R2-D2** знову зник)
- **П'ятниця:** *медитація* у барокамері. Бо діти.

## IV. Сімейні справи

> "**Люк, я твій батько.**"
>
> — *Так, дядьку, ми вже зрозуміли. Ти на весілля прийдеш?*

Знайшовся син — Люк, та ще й донька — Лея.
Вейдер думав: "От тобі й *маєш*, нащо мені все це?"
А Принцеса йому: "Ти зруйнував мою планету,
але... добре, обійму тебе на Ендорі. Один раз."

## V. Технічні недоліки

```
   ▄▄▄▄▄▄▄▄
   █  ▄▄  █     ASUS X-WING ROUTER
   █ █▓▓█ █     Signal:    ░░░░░░░░ 0%
   █  ▀▀  █     Ping:      ∞ мс
   ▀▀▀▀▀▀▀▀     Status:    Знищено
```

Коли броня важить **120 кг**,
а ти ще й **астматик** на повний робочий день,
складно бути ефектним. Біг — заборонено.
Сходи — лише ліфтом. *Йога* — теоретично, але... *хх-пшш...*

## VI. Покаяння (драматична частина)

На Ендорі, серед **евоків** (тих самих плюшевих),
Вейдер нарешті зробив правильний вибір:
**скинув Імператора в шахту**.
Класичний хід — у кожного є мрія так зробити з начальником.

> Маска впала. Під нею — *стомлений батько*.
> "Скажи... сестрі... що я її... любив..."
> *(зворушливо. Підносять серветки.)*

## VII. Епілог з мораллю

```
   .-=  Мораль  =-.
  /                \
 |  Не носи маску   |
 |  довше, ніж      |
 |  потрібно.       |
 |                  |
 |  І не працюй     |
 |  з Палпатіним.   |
  \                /
   `--------------'
```

*Кінець балади.*

**Ефекти, які ця поема перевіряє:**
- Кирилиця з українськими **і, ї, є, ґ** (вимагає `cp1125`, не `cp866`)
- Заголовки, абзаци, списки, таблиці, цитати
- Жирний (**Дарт Вейдер**), курсив (*іронічно*)
- Кодові блоки з ASCII-арт (без перекодування)
- Вкладений курсив у цитатах
- Змішаний скрипт (R2-D2, Дарт Vader, ASUS X-WING)

**Як надрукувати** на Citizen CT-S2000 з підтримкою української:

```toml
# ~/.config/claude-teletype/config.toml
[printer.profiles.citizen-cts2000-ua]
description = "Citizen CT-S2000 з кодовою сторінкою для української"
init = "1b40"
reset = "1b40"
bold_on = "1b4501"
bold_off = "1b4500"
underline_on = "1b2d01"
underline_off = "1b2d00"
end_of_response_sequence = "1b64051d5600"
formfeed_on_close = false
instant_output = true
columns = 42
buffer_bytes = 128
codepage_command = "1b7411"   # ESC t N — підставте N з мануалу вашої прошивки
text_codec = "cp1125"          # Python codec для української CP1125
```

> Точне значення `N` у `1b74NN` залежить від прошивки. Перевірте мануал
> свого CT-S2000 — типові варіанти: 17 (CP866), 28 (CP1125 в деяких
> прошивках), 47 (WPC1125). Якщо літери `і/ї/ґ` друкуються як `?`,
> підберіть інше число.
